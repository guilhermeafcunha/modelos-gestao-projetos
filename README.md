# Modelos de Documentos de Gestão de Projetos

Kit de modelos para **Engenheiros de Produção** e **Gerentes de Projetos**, alinhado a:

| Referência | Uso neste kit |
|---|---|
| **ABEPRO** – Áreas da Engenharia de Produção | Gestão de projetos se insere em *Engenharia Organizacional*, com interfaces em Qualidade, Operações, Econômica, Trabalho e Sustentabilidade |
| **PMI – PMBOK® Guide 7ª e 8ª ed.** + **Exame PMP (ECO)** | Princípios, domínios de desempenho e processos/artefatos de planejamento |
| **ISO 21502:2020** / **ABNT NBR ISO 21500** | Gerenciamento de projetos, programas e portfólios |
| **ISO 31000:2018** | Gestão de riscos |
| **ISO 30401:2018** | Sistemas de gestão do conhecimento |
| **PRINCE2® 7ª ed.**, **Agile Practice Guide**, **Scrum Guide 2020**, **SAFe 6.0**, **Disciplined Agile** | Abordagens preditiva, ágil e híbrida |
| **Lean Six Sigma (DMAIC)**, **PDCA**, **OKR**, **ESG / ISO 14001** | Melhoria contínua, metas e sustentabilidade |

> Cada modelo traz: objetivo, base normativa, campos para preencher (`[entre colchetes]`), exemplos e um checklist de qualidade.

## Mapa PMBOK × ABEPRO

| Domínio de desempenho (PMBOK 7) | Área ABEPRO relacionada |
|---|---|
| Partes Interessadas | Eng. Organizacional · Eng. do Trabalho |
| Equipe | Eng. do Trabalho (ergonomia, organização do trabalho) |
| Abordagem de Desenvolvimento e Ciclo de Vida | Eng. do Produto · Eng. Organizacional |
| Planejamento | Pesquisa Operacional · Eng. Econômica |
| Trabalho do Projeto | Eng. de Operações e Processos · Logística |
| Entrega | Eng. da Qualidade · Eng. do Produto |
| Medição | Eng. da Qualidade · Eng. Econômica |
| Incerteza | Eng. Organizacional (gestão de riscos) · Pesquisa Operacional |

> O PMBOK 8ª edição reorganiza os domínios (Governança, Escopo, Cronograma, Finanças, Partes Interessadas, Recursos e Riscos) e retoma a visão por processos. Os modelos daqui citam as duas edições quando aplicável.

## Como usar
1. Copie o modelo para a pasta do seu projeto.
2. Substitua tudo que está em `[colchetes]`.
3. Apague as linhas de exemplo (marcadas com *Ex.:*).
4. Use o checklist do final de cada modelo antes de aprovar.
