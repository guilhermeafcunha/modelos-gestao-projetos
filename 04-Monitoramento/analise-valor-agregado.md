## 1. Fórmulas
| Sigla | Nome | Fórmula | Interpretação |
|---|---|---|---|
| PV | Valor planejado | — | Quanto deveria estar feito (R$) |
| EV | Valor agregado | % concluído × orçamento | Quanto está feito (R$) |
| AC | Custo real | — | Quanto foi gasto |
| SV | Variação de prazo | EV − PV | < 0 = atrasado |
| CV | Variação de custo | EV − AC | < 0 = acima do orçamento |
| SPI | Índice de desempenho de prazo | EV / PV | < 1 = atrasado |
| CPI | Índice de desempenho de custo | EV / AC | < 1 = acima do orçamento |
| EAC | Estimativa no término | BAC / CPI *(desempenho atual continua)* | |
| | | AC + (BAC − EV) *(desvio foi pontual)* | |
| | | AC + (BAC − EV) / (CPI × SPI) *(prazo e custo influenciam)* | |
| ETC | Estimativa para terminar | EAC − AC | |
| VAC | Variação no término | BAC − EAC | |
| TCPI | Índice de desempenho para terminar | (BAC − EV) / (BAC − AC) | > 1,1 = meta difícil |
| SPI(t) | Prazo agregado | ES / AT | Mais confiável no fim do projeto |
